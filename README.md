# Fokir Website Template — HTML & CSS

A personal portfolio website built using **pure HTML5 and CSS3**, inspired by the Fokir portfolio design. This website demonstrates front-end development fundamentals through structured page sections, custom CSS styling, responsive layout adjustments, and interactive visual effects without JavaScript or CSS frameworks.

## 📌 Project Overview

Fokir is a personal portfolio template designed to showcase a profile, services, portfolio projects, client feedback, blog posts, and contact information in a clean, organized layout.

This implementation focuses on recreating the reference design using HTML and CSS while practicing page structure, layout techniques, styling, and CSS-based interactions.

## ✨ Key Features

- **Fixed Navigation Bar:** Section links and smooth scrolling for in-page navigation.
- **Hero Section:** Full-screen background image, dark overlay, and centered typography.
- **About Section:** Profile image, personal information, social icons, and call-to-action buttons.
- **Services Section:** Service layouts with icons and hover effects.
- **Portfolio Gallery:** Image grid with hover overlays and category controls.
- **Statistics Section:** A dedicated area for portfolio statistics.
- **Client Feedback:** Testimonial layout with a profile image and rating stars.
- **Blog Section:** Blog cards featuring images, text, and an embedded YouTube video.
- **Contact Form:** Styled input fields for contact information and messages.
- **Footer:** Social icons and copyright information.

## 🛠️ Technologies & Tools

| Technology        | Purpose                                          |
| ----------------- | ------------------------------------------------ |
| HTML5             | Page structure and content                       |
| CSS3              | Styling, layout, transitions, and visual effects |
| CSS Media Queries | Layout adjustments at selected screen widths     |
| Google Fonts      | Custom typography                                |
| Font Awesome 6    | Icons and visual elements                        |
| GitHub Pages      | Deployment and hosting                           |

**No JavaScript or CSS frameworks are used in this implementation.**

## 💡 Technical Highlights

- Structured a complete multi-section landing page.
- Organized HTML and CSS into separate files.
- Used CSS floats and Flexbox to arrange page elements.
- Applied pseudo-elements (`::before` and `::after`) for decorative styling.
- Created hover animations using `opacity`, `transform`, and `transition`.
- Worked with background images, positioning, spacing, and typography.
- Implemented smooth scrolling and anchor-based navigation.
- Used media queries to adjust selected layouts across screen widths.
- Integrated external font and icon libraries.

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Abdelrahmankishk/Fokir-Template.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Fokir-Template
   ```

3. Open `index.html` in your browser.

No package installation or build process is required.
