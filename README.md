# Fokir Template — HTML & CSS

A responsive personal portfolio website built using **pure HTML5 and CSS3**, inspired by the Fokir portfolio design. The Template focuses on structuring a complete landing page, styling modern UI sections, and creating interactive visual effects using CSS without JavaScript or CSS frameworks.

## 🌐 Live Demo

**[View the Deployed Website](https://abdelrahmankishk.github.io/Fokir-Template/)**

---

## 📌 Project Overview

Fokir is a personal portfolio website template designed to present a developer's profile, services, portfolio, client feedback, blog posts, and contact information in a clean, organized layout.

This Template is an independent implementation inspired by the original Fokir design, developed to strengthen front-end development skills through practical HTML and CSS work.

## ✨ Key Features

- **Fixed Navigation Bar:** A persistent navigation menu with anchor links for smooth navigation between page sections.
- **Hero Section:** A full-screen introduction featuring a background image, dark overlay, and centered typography.
- **About Section:** A profile layout with an image, social media icons, personal information, and call-to-action buttons.
- **Services Section:** A structured service layout with icons and CSS hover effects.
- **Portfolio Gallery:** An image gallery featuring overlay effects and visual category controls.
- **Statistics Section:** A dedicated section displaying portfolio-related statistics.
- **Client Feedback:** A testimonial layout featuring a client profile, feedback text, and rating stars.
- **Blog Section:** Blog post cards with images, descriptions, and an embedded YouTube video.
- **Contact Form:** A styled form with name, email, subject, and message fields.
- **Footer:** Social media icons and copyright information.

## 🛠️ Technologies & Tools

| Technology | Purpose |
|---|---|
| HTML5 | Structuring the website and its content |
| CSS3 | Styling, layouts, animations, and visual effects |
| CSS Media Queries | Adjusting selected layouts at different screen widths |
| Google Fonts | Custom typography |
| Font Awesome 6 | Icons and visual elements |
| GitHub Pages | Website deployment and hosting |

**No JavaScript or CSS frameworks are used in this implementation.**

## 💡 Technical Highlights

This project demonstrates practical experience with:

- Organizing a multi-section webpage using HTML.
- Separating page structure from styling through external CSS files.
- Applying CSS layouts using floats and Flexbox.
- Using pseudo-elements (`::before` and `::after`) for decorative elements.
- Creating image overlays and hover transitions using `opacity`, `transform`, and `transition`.
- Working with background images, positioning, spacing, and typography.
- Implementing smooth scrolling and in-page navigation.
- Applying media queries to adjust card layouts at tablet and desktop breakpoints.
- Integrating external font and icon libraries.

## 🚀 Run Locally

To run the project on your local machine:

1. Clone the repository:

   ```bash
   git clone https://github.com/Abdelrahmankishk/Fokir-Template.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Fokir-Template
   ```

3. Open `index.html` in your browser.

No package installation, build process, or development server is required.
